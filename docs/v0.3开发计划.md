# v0.3 开发计划

**版本**：0.3.0
**仓库**：<https://github.com/qcytkk/win-desktop-icon-backup-manager>
**版本管理规范**：见 [版本管理.md](./版本管理.md)

## 一、目标

本版解决三个问题：

1. **版本管理**：开始按语义化版本迭代，统一版本号、更新日志与发布流程。
2. **开机自启 + 隐藏守护**：登录后自动在系统托盘运行，显示模式/刷新率变化后自动恢复当前布局。
3. **桌面右键菜单**：在桌面空白处右键可直接「备份当前桌面布局」，并可在设置里关闭。

## 二、功能设计

### 2.1 版本管理

- 版本号唯一来源：`package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 三处保持一致。
- 每次发布更新 `CHANGELOG.md`，标签使用 `v<版本>`。
- 发布产物命名保持纯 ASCII：`desktop-icon-backup_<版本>_x64-setup.exe`、`desktop-icon-backup_<版本>_portable.exe`。
- 详细流程见 [版本管理.md](./版本管理.md)。

### 2.2 开机自启 + 隐藏守护

**启动方式**

- 设置项：`autoStart`（默认开启）。
- 开关打开时写入：
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
  值名 `DesktopIconBackup`，内容 `"<exe 完整路径>" --autostart`。
- 开关关闭时删除该值。
- 便携版被移动后路径会失效，需重新打开软件开关一次（文档中注明）。

**托盘形态**

- 主窗口配置改为 `create: false`，不随进程启动自动创建 WebView。
- 托盘图标常驻，菜单包含：
  - 显示主界面
  - 退出
- 托盘菜单文案按当前语言显示（6 种语言）。
- 双击 / 左键点击托盘图标显示主界面。
- 自启动模式（`--autostart`）：不创建主窗口，只在托盘运行；用户点托盘才创建窗口。
- 手动启动：创建并显示主窗口。
- 关闭主窗口时：
  - `autoStart` 开启 → 拦截关闭，隐藏到托盘；
  - 关闭 `autoStart` → 正常退出。

**守护逻辑**

- 活动布局记录在应用配置目录 `guard.json`：
  ```json
  { "backupId": "...", "scaleMode": "current" }
  ```
  每次应用布局成功后写入（`apply_backup` 命令内）。
- 登录恢复：`--autostart` 启动后等待 Explorer 桌面就绪（轮询桌面项数 > 0），
  再延时 8 秒（等显示驱动/DPI 稳定），应用一次 `guard.json` 记录的活动布局。
- 显示变化：创建隐藏的顶层 Win32 窗口，监听：
  - `WM_DISPLAYCHANGE`（分辨率 / 刷新率 / 显示模式变化）
  - `WM_SETTINGCHANGE`（工作区等设置变化）
  事件后 debounce 3 秒再恢复，避免在一次显示切换中被多次重排。
- 恢复后校验：重新读取桌面图标坐标，命中率低于 90% 则重试，最多 3 次（间隔 3 秒）。
- 守护进程只在上述时机动作，不做定时强制重放，避免和用户手动拖动图标冲突。
- 日志：应用配置目录 `guard.log`，记录启动、恢复、重试与失败原因；超过 1MB 时重写。

**单实例**

- 使用 `tauri-plugin-single-instance`：重复启动时唤起已有实例的主界面。
- `--backup-now` 模式不参与单实例，允许与主程序并行执行（只读桌面 + 写备份目录）。

### 2.3 桌面右键菜单「备份当前桌面布局」

**注册位置**

```
HKCU\Software\Classes\DesktopBackground\Shell\DesktopIconBackup
  (默认)        = 备份当前桌面布局        # 菜单文案，按当前语言写入
  Icon          = <exe 完整路径>
  Position      = Bottom
  \command
    (默认)      = "<exe 完整路径>" --backup-now
```

**开关**

- 设置项：`contextMenu`（默认开启）。
- 开启时写入上述键，关闭时递归删除。
- 切换语言后重新写入菜单文案。

**执行方式**

- 新增 `--backup-now` 启动模式：
  - 不创建主窗口、不创建托盘；
  - 复用现有备份流程（显示器信息 + 图标采集 + 注册表快照 + 写入备份目录）；
  - 完成后弹出系统消息框：成功显示「已备份当前桌面布局（N 个图标）」，失败显示原因；
  - 结束进程。
- 备份命名使用现有默认命名规则（`备份 YYYY-MM-DD HH:mm`）。

## 四、验收标准

1. 设置页开启「开机自启」后，`HKCU\...\Run` 出现正确命令行；关闭后消失。
2. 重启登录后，软件不出主窗口，只在托盘显示图标；桌面布局在延时后自动恢复为活动布局。
3. 在系统设置里切换刷新率，3–10 秒内布局自动恢复（日志有记录）。
4. 关闭主窗口时，自启开启则隐藏到托盘；托盘菜单可显示主界面、可退出。
5. 设置页开启「右键菜单」后，桌面空白处右键出现「备份当前桌面布局」；
   点击后生成一条新备份并弹出成功提示；关闭开关后菜单消失。
6. 旧版 `settings.json`（无新字段）加载后不报错，两个开关按默认开启。
7. `cargo check`、`cargo test --lib`、`npm run build` 全部通过。
