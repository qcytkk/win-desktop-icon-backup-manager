# 字体大小功能 · 实施计划

**目标**：把设置页「字体大小」从占位改为 4 档可调，全站文字按角色统一缩放，并保证最小字号。

## 1. 档位与字号

| 角色 | 用途 | 小 | 标准（默认） | 大 | 特大 |
|---|---|---|---|---|---|
| 辅助字 | 徽标、元信息、表头、提示、路径、脚注 | 12 | 14 | 16 | 18 |
| 正文 | 按钮、列表、设置项、说明、弹窗正文 | 14 | 16 | 18 | 20 |
| 小标题 | 卡片名称、分区标题、弹窗标题 | 16 | 18 | 20 | 22 |
| 大标题 | 主标题、页面大标题 | 20 | 22 | 24 | 26 |

规则：**小档即规范下限**，每升一档各角色 +2px。

行高随档位微调：辅助 1.5、正文 1.45、小标题 1.35、大标题 1.25。

## 2. 实现方式

根节点属性控制档位：

```css
:root{
  --fs-aux:14px; --fs-body:16px; --fs-title:18px; --fs-display:22px;
}
:root[data-font-size="small"] { --fs-aux:12px; --fs-body:14px; --fs-title:16px; --fs-display:20px; }
:root[data-font-size="large"] { --fs-aux:16px; --fs-body:18px; --fs-title:20px; --fs-display:24px; }
:root[data-font-size="xlarge"]{ --fs-aux:18px; --fs-body:20px; --fs-title:22px; --fs-display:26px; }
```

- 删除现有 `--text-caption / --text-body / --text-title` 及各处硬编码 `font-size`，统一改为 `var(--fs-*)` + 对应行高。
- 设置项 4 个按钮：小 / 标准 / 大 / 特大，点击切换根节点属性并写入 `localStorage`（key：`ui.fontSize`），启动时恢复，默认标准。
- 移除「字体大小」区的「即将支持」标签和按钮的 `aria-disabled`，改为可操作。
- 控件尺寸联动：按钮高度、列表行高、卡片内边距用 `calc(var(--fs-body) + Npx)`，避免特大档文字被裁切。

**需要重新分配字号的现有文本（示例）**

- 辅助字：时间、图标数、表头、徽标、提示条、路径、脚注、进度说明
- 正文：所有按钮、排序选项、设置项、列表单元格、确认弹窗正文
- 小标题：卡片名称、设置分区标题、预览弹窗标题
- 大标题：工具栏「备份」主标题、空态标题
